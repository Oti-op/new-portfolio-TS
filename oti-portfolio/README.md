# Oti's Portfolio

Welcome to Oti's Portfolio! This project showcases the work and skills of Oti Oseji, a software developer passionate about creating innovative solutions.

## Project Structure

The project is organized as follows:

```
oti-portfolio
├── index.html        # Home page with introduction and recent projects
├── projects.html     # Page listing all projects with details
├── blog.html         # Blog page with a focus on software development
├── cv.html           # CV page with education, experience, and skills
├── css
│   └── style.css     # Custom styles for the website
├── js
│   └── script.js     # JavaScript for theme toggle functionality
├── assets
│   └── images        # Directory containing images used in the website
└── README.md         # Documentation for the project
```

## Features

- **Responsive Design**: The website is designed to be fully responsive, ensuring a great user experience on all devices.
- **Theme Toggle**: Users can switch between light, dark, and system themes.
- **Project Showcase**: Detailed project cards highlight the skills and technologies used in each project.
- **Blog Section**: A dedicated space for sharing insights and updates (currently no posts available).
- **Downloadable CV**: Users can download Oti's CV directly from the website.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd oti-portfolio
   ```
3. Open `index.html` in your web browser to view the portfolio.

## Additional Notes

- Ensure you have an internet connection to load Tailwind CSS via CDN.
- Customize the content in each HTML file to reflect your personal information and projects.
- Update the `assets/images` directory with your avatar and any other images you wish to use.
